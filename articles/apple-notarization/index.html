shield Apple公証とは

野良アプリは危険？Apple公証（Notarization）とサンドボックスで守られたサイドローディングの安全性を解説。

lightbulb サイドローディング＝危険？それは思い込みかもしれません

「App Store 以外からアプリをインストール（サイドローディング）すると危険」こんなイメージを持っていませんか？実は、この認識は必ずしも正確ではありません。

AltStore や SideStore といった正規のツールを経由してアプリをインストールする場合、Apple の厳重なセキュリティシステムに守られています。 App Store のアプリと比べても、その安全性はほぼ変わりません。

info この記事について

この記事では、Apple公証（Notarization）という技術的なセキュリティシステムについて解説しています。 代替マーケットプレイス（AltStore PAL等）経由で配布されるすべてのアプリは、Apple公証が必須です。 一方、無料の開発者アカウントで直接IPAファイルをインストールする場合は、公証の対象外となります。 エミュレータ（Delta、UTMなど）はオープンソースで開発されており、透明性が高いことも安全性の根拠です。

verified Apple公証（Notarization）とは

Apple公証（Notarization）とは、App Store 外で配布されるアプリに対して、Apple が自動チェックと人間によるレビューを組み合わせて行うベースラインセキュリティレビューのことです。代替マーケットプレイス（AltStore PAL等）経由で配布されるすべてのiOSアプリは公証が必須です。主な役割は2つです：

マルウェアスキャン
ウイルス・スパイ自動検査
security
改ざんチェック
DL中の改ざんを検出
store
App Store審査
品質・ポリシーの総合審査
verified
公証
自動+人的セキュリティ検査

App Store審査：人間による品質・ポリシーの総合審査。コンテンツの適切性やビジネスモデルも審査対象。数時間〜数日かかることも。

公証（Notarization）：自動チェックと人間によるレビューの組み合わせで実施。マルウェア・ウイルスの検出、アプリの基本機能の確認、重大な詐欺の防止に焦点を当てたベースラインレビューです。

重要な違い：公証はセキュリティ・プライバシー・デバイス保全に特化した基準レビューであり、App Storeのコンテンツ品質基準やビジネス慣行の審査は含まれません。

verified 重要ポイント

公証済みアプリであれば、少なくともウイルス感染のリスクは極めて低いということです。App Store 審査は「品質審査」、公証は「セキュリティチェック」に特化しています。

公証には重要な機能があります。もし公証通過後にアプリがマルウェアだと判明した場合、Apple は後からその「公証チケット」を無効化（Revocation）できます。

warning キルスイッチのプロセス

危険なアプリ判明 → Apple が公証を無効化 → 世界中のデバイスでアプリ起動不可 → ユーザーは自動的に保護される

  • 世界中のデバイスでそのアプリが起動できなくなる
  • 既にインストールされているユーザーも影響を受ける
  • 新規ダウンロードはもちろんブロックされる

Apple は危険なアプリをリアルタイムで無効化することができます。

ぶんちゃんのアドバイス

Appleが「リモコン」でアプリを止められる！
もし危険なアプリが見つかっても、世界中で一斉に起動不可にできるんだよ🛡️

Apple 公証を受けるには、Apple Developer Programに登録する必要があります。そのため、以下の身元確認が必須です：

  • 本名と住所の登録
  • クレジットカードの登録
  • 開発者としての履歴確認

このため、匿名でウイルスをばら撒くことは非常に難しいです。「身元が特定される可能性がある」という心理的なハードルが、悪質な開発者を遠ざける効果があります。

library_books 関連する技術用語の解説

App Store を通さずに配布するアプリは、ダウンロード後、デバイスが起動時に Apple のサーバーに接続して「公証チケット」の有効性を確認します。このチケットが無効になると、アプリは起動できなくなります。

公証チケットを実際のアプリに「貼り付ける」プロセスのことです。AltStore や SideStore は、このプロセスを自動で実行しています。

アプリ起動時に、デバイスが公証チケットの有効性をリアルタイムで確認するプロトコルです。これにより、Apple は危険なアプリをリアルタイムで無効化できます。

help よくある質問

ほぼ安全ですが、100%ではありません。新種のマルウェアが検知されない可能性はありますが、そのリスクはApp Storeより高いわけではありません。

公証済みかどうかの確認が難しいため、AltStoreやSideStoreなどの信頼できるツールを使うことをお勧めします。

サンドボックスだけでは完全には防げませんが、iOSではカメラ・マイク・位置情報へのアクセスにユーザーの明示的な許可が必要です。

セキュリティ面では大きな差はありません。App Storeは「品質審査」、公証は「セキュリティチェック」に特化しています。

warning 重要：7日署名と公証の関係

warning 7日署名では公証が失われます

AltStoreやSideStoreで無料の開発者アカウントを使いIPAファイルとしてインストールしたアプリは、7日ごとに再署名が必要です。 この再署名プロセスでは、元の公証ステータスが失われます。 つまり、初回インストール時は公証済みアプリとして保護されますが、 7日後の自動更新以降は、公証なしの状態で動作することになります。 ただし、iOSのサンドボックス構造により、アプリはシステムから隔離されているため、 公証が失われても基本的な安全性は維持されます。

check_circle 7日制限なしで利用する方法
  • 代替マーケットプレイス経由でインストール：AltStore PAL等の代替マーケットプレイスからインストールしたアプリは、7日制限なしで永続的に利用可能です。公証も維持されます
  • 有料開発者アカウント（年額99ドル）を使用：永続的な署名が可能になります
  • App Storeから配信されるアプリを使用：App Store経由のアプリは公証が永続的に維持されます
